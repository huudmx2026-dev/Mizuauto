# Mizuauto

## Tiếng Việt

Đây là phiên bản Roblox Manager được mình tùy chỉnh và mở rộng với sự hỗ trợ của **OpenAI Codex (ChatGPT)**.

Mục tiêu của dự án là khắc phục một số lỗi trong phiên bản gốc, cải thiện độ ổn định khi tham gia game, sửa các tính năng gặp sự cố và bổ sung nhiều tiện ích nhằm giúp việc quản lý nhiều tài khoản Roblox trở nên thuận tiện hơn.

Toàn bộ phần chỉnh sửa và bổ sung được thực hiện với sự hỗ trợ của AI Codex. Đây không phải là phần mềm được mình tự viết hoàn toàn từ đầu mà được phát triển dựa trên nền tảng Roblox Manager hiện có.

## Các tính năng được bổ sung

### 1. Giới hạn RAM cho Roblox

Cho phép thiết lập giới hạn RAM sử dụng cho Roblox, hỗ trợ những máy tính có dung lượng RAM thấp kiểm soát mức sử dụng bộ nhớ khi chạy nhiều tài khoản.

*Lưu ý: Việc giới hạn RAM quá thấp có thể khiến FPS không ổn định, giảm hiệu suất và gây giật lag trong quá trình chơi game.*

### 2. Hiển thị tên tài khoản trên từng tab

Thay thế tên hiển thị Roblox mặc định bằng tên tài khoản tương ứng trên tab, giúp dễ dàng nhận biết và tìm kiếm tài khoản khi mở nhiều cửa sổ cùng lúc.

### 3. Hiển thị trạng thái cửa sổ Roblox

Bổ sung trạng thái hoạt động của từng tab ngay trên Panel. Có thể nhanh chóng xác định cửa sổ Roblox tương ứng và mở trực tiếp thông qua nút bên cạnh username mà không cần tìm kiếm thủ công.

### 4. Tùy chỉnh kích thước cửa sổ tự do

Cho phép kéo thả và thay đổi kích thước cửa sổ Roblox theo nhu cầu, hạn chế những giới hạn kích thước mặc định và cải thiện trải nghiệm khi sắp xếp nhiều cửa sổ.

### 5. Tự động điều chỉnh kích thước cửa sổ

Tự động thiết lập kích thước mong muốn khi mở các tab Roblox mới, không cần phải điều chỉnh thủ công từng cửa sổ.

### 6. Sắp xếp cửa sổ Roblox

Bổ sung hai phương thức sắp xếp cửa sổ:

- **Trải đều:** Phân bố các cửa sổ gọn gàng trên màn hình.
- **Xếp chồng:** Sắp xếp các cửa sổ chồng lên nhau theo thứ tự.

### 7. Tùy chỉnh thư mục lưu dữ liệu Note

Cho phép lựa chọn thư mục lưu dữ liệu Note của các tài khoản. Điều này cũng tạo điều kiện để các nhà phát triển Script xây dựng những công cụ đọc, hiển thị hoặc xử lý dữ liệu theo nhu cầu riêng.

### 8. Tùy chỉnh hình nền Panel

Cho phép thiết lập hình ảnh Background theo sở thích, giúp giao diện quản lý có tính cá nhân hóa hơn.

## Các cải tiến khác

## English

This is a customized and extended version of Roblox Manager, developed with the assistance of **OpenAI Codex (ChatGPT)**.

The goal of this project is to fix several issues found in the original version, improve game-joining reliability, resolve malfunctioning features, and introduce additional utilities to make managing multiple Roblox accounts easier and more convenient.

All modifications and additional features were implemented with the assistance of AI Codex. This software was not written entirely from scratch by me; it is based on the existing Roblox Manager project.

## Added Features

### 1. Roblox Memory Limit

Allows users to set a RAM usage limit for Roblox, helping computers with limited memory manage resource consumption when running multiple accounts.

*Note: Setting the memory limit too low may result in unstable FPS, reduced performance, and stuttering during gameplay.*

### 2. Display Account Names on Tabs

Replaces the default Roblox window title with the corresponding account name, making it easier to identify and locate specific accounts when multiple windows are open.

### 3. Roblox Window Status Indicator

Displays the status of each Roblox window directly in the panel. Users can quickly identify the corresponding window and bring it into focus using the button next to the username, without having to search through multiple windows manually.

### 4. Unrestricted Window Resizing

Allows users to freely resize Roblox windows by dragging their edges, removing the usual size restrictions and providing greater flexibility when arranging multiple windows.

### 5. Automatic Window Resizing

Automatically applies the preferred window dimensions whenever a new Roblox window is opened, eliminating the need to manually resize each window.

### 6. Window Arrangement

Provides two window arrangement modes:

- **Tile:** Distributes windows evenly across the screen.
- **Cascade:** Arranges windows in an overlapping, layered layout.

### 7. Custom Note Data Directory

Allows users to choose a custom directory for storing account Note data. This also provides developers with the flexibility to create scripts and tools that read, display, or process this data according to their needs.

### 8. Custom Panel Background

Allows users to set a custom background image for the panel, providing a more personalized interface.

## Additional Improvements

In addition to the features listed above, this version also focuses on:

- Fixing several game-joining issues.
- Resolving bugs and improving malfunctioning features.
- Improving the overall experience when managing multiple Roblox accounts.
- Retaining the existing features from the original Roblox Manager.
